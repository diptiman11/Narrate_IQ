# Narrate IQ

## Business Intelligence Intelligence-to-Action Engine

Narrate IQ is an AI-powered KPI intelligence platform that detects
material business metric movements, identifies likely drivers,
communicates evidence-backed explanations, and recommends actions.

## Problem

Businesses have KPIs spread across multiple systems and data sources.
Traditional dashboards show what changed but often do not explain why
it changed or what action should be taken.

## Solution

Narrate IQ combines:

- deterministic KPI computation
- anomaly detection
- contribution analysis
- business context
- confidence scoring
- evidence lineage
- LLM-assisted narrative generation
- action recommendations

## Architecture
